# Internationalization (i18n)

The application is bilingual: **Indonesian (`id`, default)** and **English (`en`)**.
Every interface string lives in `src/lib/i18n`; components never hard-code copy.

## Layout

```
src/lib/i18n/
  locale.ts            locale primitives, URL helpers, Accept-Language parsing, plurals
  translate.ts         translator: lookup, interpolation, plural fallback, key typing
  interpolate.ts       {{placeholder}} replacement (shared with the browser bundle)
  format.ts            Intl date/number/currency/relative/list formatters
  react.tsx            I18nProvider, useI18n(), useTranslate()
  client.ts            serialisable subset for client scripts
  browser.ts           documentLocale() for client-only React trees
  status.ts            article status -> translation key
  content/documents.ts long-form About/Privacy/Terms documents
  messages/            the message catalogue, one file per namespace
```

`messages/index.ts` is the single registry and `.id` is the source of truth for the
key set. `en` is typed as `typeof id` in every namespace file, so adding a key to
one language without the other is a TypeScript error.

## Server usage

```ts
const t = c.get('t')          // translator for the negotiated request locale
const locale = c.get('locale')

t('seo.articlesTitle', { site: settings.title })
t('common.pieceCount', { count: 12 })
```

`c.get('locale')` is set per request by `src/server/locale.ts`. Never set a global
language on a translator; always pass the locale (or use the request-bound `t`).

## React usage

Components are rendered inside `<I18nProvider>` by `src/server/render-page.tsx`,
so they simply call the hook:

```tsx
const { t, href, locale, formatDate, formatNumber } = useI18n()

<h1>{t('listing.allArticlesTitle')}</h1>
<a href={href('/articles')}>{t('nav.articles')}</a>
<time>{formatDate(article.publishedAt, 'short')}</time>
```

- `href(path)` adds the locale prefix on public pages and is a no-op in the desk.
- `formatDate(value, 'long' | 'short' | 'month' | 'weekday' | 'datetime' | 'time')`
  replaces the old `formatDate` from `src/lib/content/html.ts`.
- `formatNumber`, `formatCurrency`, `formatPercent` wrap `Intl`.

Client-only React trees (the editor) wrap their root in
`<I18nProvider locale={documentLocale()}>` from `src/lib/i18n/browser.ts`.

## Message rules

- Keys are dot paths: `namespace.section.name`.
- Values are **strings only** (no functions, no JSX, no `as const`).
- Interpolation: `'{{count}} pieces'`, called as `t('...', { count })`.
- Plurals: the base key is the plural form; add `_one` for the singular in
  English. `t('common.pieceCount', { count: 1 })` resolves `common.pieceCount_one`
  when the locale needs it and otherwise the base key.
- Indonesian is the default language and the final fallback.
- Never translate identifiers: slugs, database values, enum values, form field
  names, API field names, code samples, or user-generated content.
